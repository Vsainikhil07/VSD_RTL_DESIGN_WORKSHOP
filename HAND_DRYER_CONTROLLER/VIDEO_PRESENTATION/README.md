## Project Demonstration Video

**Digital Hand-Dryer Auto-Off Controller — RTL to GDSII**

Watch the complete project demonstration:

[Watch Project Demonstration Video on Google Drive](https://drive.google.com/file/d/13fieYxoLk4f7tm7dOlQWfu6Ah_aosvdK/view)

### Topics Covered
- Verilog RTL design and functional verification
- Simulation using Icarus Verilog and GTKWave
- Synthesis using Yosys
- Floorplanning, placement, and Clock Tree Synthesis (CTS)
- Routing and Design Rule Check (DRC)
- Static Timing Analysis (STA)
- Final GDSII layout generation

**Tools:** Verilog HDL, Icarus Verilog, GTKWave, Yosys, OpenLane, and SKY130 PDK.
