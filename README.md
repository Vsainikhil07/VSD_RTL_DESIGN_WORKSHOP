## 🚀 Main Project: Digital Hand-Dryer Auto-Off Controller

A digital hand-dryer controller designed using Verilog HDL and implemented through the RTL-to-GDSII flow using the SKY130 HD standard-cell library and OpenLane.

### Project Highlights

- **RTL Design:** Verilog HDL controller and testbench.
- **RTL Simulation:** Functional verification using Icarus Verilog and GTKWave.
- **Synthesis:** Logic synthesis using Yosys and technology mapping.
- **Physical Design:** Floorplanning, placement, clock-tree synthesis, and routing.
- **Timing Analysis:** Post-route static timing analysis.
- **Verification:** DRC, LVS, antenna, and circuit verification reports.
- **Final Layout:** GDSII layout and supporting physical design files.

### Tools Used

Verilog HDL · Icarus Verilog · GTKWave · Yosys · ABC · OpenLane · OpenROAD · SKY130 HD · Magic · KLayout · Netgen · OpenSTA
